# Музыкальные треки для УмножиКрафт

В эту папку нужно добавить следующие MP3 файлы:

1. **mine-theme.mp3** - Шахтёрский марш (основная тема)
2. **cave-ambient.mp3** - Пещерная мелодия (фоновая музыка)
3. **adventure.mp3** - Приключение (тема исследования)
4. **victory.mp3** - Победа (фанфары при достижении)

## Где взять музыку?

Вы можете использовать:
- Бесплатные звуки с [Freesound.org](https://freesound.org/)
- Музыку из [OpenGameArt](https://opengameart.org/)
- Сгенерировать через AI инструменты (Suno, Udio)
- Написать свою собственную музыку

## Требования
- Формат: MP3
- Рекомендуемое качество: 128-192 kbps
- Длительность: 1-3 минуты (для зацикливания)
