# УмножиКрафт (Umnozhikraft) ⛏️

Образовательная игра для тренировки таблицы умножения в стиле Minecraft, разработанная на **Vue 3** + **Pinia** с использованием архитектуры **Feature-Sliced Design (FSD)**.

## 🎮 О игре

**УмножиКрафт** — это увлекательная игра, где дети решают примеры на умножение, чтобы ломать блоки, добывать алмазы и прокачивать своего шахтёра.

### Особенности:
- 🧠 **Тренировка таблицы умножения** от ×2 до ×9
- ⛏️ **Система прогрессии** — открывайте новые таблицы по мере повышения уровня
- 💎 **Алмазная экономика** — покупайте новые кирки и скины
- 👾 **Битвы с мобами** — зомби и криперы появляются случайно
- 🔥 **Комбо-система** — бонусы за серию правильных ответов
- 🌱 **Режим "Новичок"** — постепенное открытие таблиц умножения
- 💾 **Сохранение прогресса** — игра автоматически сохраняется в localStorage

## 📁 Структура проекта (FSD)

Проект организован по методологии **Feature-Sliced Design**, которая обеспечивает модульность и масштабируемость кода:

```
src/
├── app/                    # Инициализация приложения
│   ├── main.js            # Настройка Pinia
│   └── styles/            # Глобальные стили
│
├── pages/                  # Страницы приложения
│   ├── start/             # Стартовая страница (выбор таблиц)
│   │   └── ui/
│   │       └── StartPage.vue
│   └── game/              # Игровая страница
│       └── ui/
│           └── GamePage.vue
│
├── widgets/                # Композитные блоки (сборки из features + entities)
│
├── features/               # Бизнес-логика и взаимодействия
│   ├── mining/            # Механика добычи блоков
│   │   └── ui/
│   │       └── LevelUpModal.vue
│   ├── selection/         # Выбор таблиц умножения
│   │   └── ui/
│   │       └── TableSelector.vue
│   └── shop/              # Магазин предметов
│       └── ui/
│           └── ShopModal.vue
│
├── entities/               # Бизнес-сущности
│   ├── player/            # Сущность игрока
│   │   └── model/
│   │       └── useGameStore.js  # Pinia store
│   ├── block/             # Сущность блока
│   │   └── model/
│   │       └── constants.js
│   └── mob/               # Сущность моба
│
├── shared/                 # Переиспользуемый код
│   ├── api/               # API запросы (если нужны)
│   ├── config/            # Конфигурация игры
│   │   └── game.js        # Параметры игры (блоки, мобы, кирки)
│   ├── lib/               # Утилиты и хелперы
│   │   └── utils.js       # Вспомогательные функции
│   └── ui/                # Переиспользуемые UI компоненты
│
├── assets/                 # Статические ресурсы
├── components/             # Базовые компоненты (не привязанные к бизнесу)
├── App.vue                 # Корневой компонент
├── main.js                 # Точка входа приложения
└── style.css               # Глобальные стили
```

### Слои FSD (по убыванию важности):

1. **app** — инициализация приложения, провайдеры, глобальные настройки
2. **pages** — полноценные страницы приложения
3. **widgets** — композиция features и entities в законченные блоки
4. **features** — действия пользователя (покупка, выбор, добыча)
5. **entities** — бизнес-сущности (игрок, блок, моб)
6. **shared** — переиспользуемая логика без привязки к бизнесу

## 🎮 Как играть

1. **Выберите таблицы умножения** для тренировки (можно несколько)
2. Нажмите **"▶ НОВАЯ ИГРА"**
3. Решайте примеры на умножение
4. За каждый правильный ответ вы ударяете киркой по блоку
5. Когда HP блока достигнет 0 — он ломается, вы получаете опыт и алмазы
6. Периодически появляются **мобы** — победите их, решая примеры
7. Покупайте новые **кирки** (больше урона) и **скины** в магазине

### Управление
- Выбор ответа — клик по варианту ответа
- Открытие магазина — кнопка "🛒 МАГАЗИН"
- Звук вкл/выкл — кнопка "🔊/🔇"

## ⚙️ Конфигурация игры

Все игровые параметры находятся в `src/shared/config/game.js`:

- **Таблицы умножения**: открываются с уровнями (×4 на уровне 2, ×5 на уровне 3 и т.д.)
- **Блоки**: земля, камень, уголь, железо, алмазная руда
- **Мобы**: зомби, крипер
- **Кирки**: деревянная, каменная, железная, золотая, алмазная
- **Скины**: классический, зомби, прораб, король шахты

## 🎯 Особенности реализации

### State Management (Pinia)
Игровое состояние управляется через Pinia store (`src/entities/player/model/useGameStore.js`):
- Статус игры (старт/игра)
- Выбранные таблицы умножения
- Прогресс игрока (уровень, опыт, алмазы)
- Текущий блок и проблема
- Активные мобы
- Инвентарь (кирки, скины)

### Сохранение прогресса
Игра автоматически сохраняется в `localStorage` после каждого значимого действия:
- Правильный ответ
- Разрушение блока
- Покупка предмета
- Повышение уровня

### Генерация примеров
- Использует выбранные таблицы умножения
- Создаёт дистракторы (неправильные варианты) на основе типичных ошибок
- Запоминает ошибочные ответы и предлагает их повторно

## 👨‍💻 Для разработчиков

### Добавление новой фичи

1. Определите слой FSD (feature, entity, widget)
2. Создайте папку с названием фичи
3. Внутри создайте структуру: `ui/`, `model/`, `lib/` (по необходимости)
4. Экспортируйте публичный API через `index.js` (если нужно)

### Пример добавления нового типа блока

```javascript
// src/shared/config/game.js
export const CONFIG = {
  blocks: [
    // ...существующие блоки
    { id: 'gold', cls: 'block--gold', name: 'Золотая руда', hp: 5, minDepth: 30, dia: 0.8, diaMax: 2, xp: 20 },
  ],
};
```
